# project-scaffold Skill

Опис
----

Цей Skill створює мінімальний «Hello World» проєкт для вказаної мови програмування та назви проєкту. Він генерує:

- структуру каталогів (папку проекту, src або аналог),
- README.md з коротким описом та командою запуску,
- початковий `.gitignore` з базовими правилами для мови,
- початковий вихідний файл з «Hello World». 

Skill приймає два аргументи:
- `language` — мова (наприклад: python, node, go, java, rust),
- `project_name` — назва проєкту (папка, яку буде створено).

Після генерації Skill перевіряє:
1. Наявність очікуваного вихідного файлу.
2. Що команда запуску (вказана в README) виконується і повертає код 0 (за потреби — у середовищі користувача).

Файлова структура (приклад для Python):

project_name/
  README.md
  .gitignore
  src/
    main.py

Приклади команд запуску, які додаються до README:
- python: `python3 src/main.py` або `python -m src.main` (якщо пакет)
- node: `node src/index.js`
- go: `go run ./src`
- java: `javac -d out src/Main.java && java -cp out Main`
- rust: `cargo run` (якщо створено Cargo.toml)

Шаблони `.gitignore` — базові для кожної мови (приклади нижче).

---

Приклад реалізації: `scripts/project-scaffold.sh`

Нижче наведено приклад bash-скрипта, який можна використовувати локально для scaffold-інгу проєкту. Скрипт створює файли та виконує базову перевірку наявності та запуску.

```bash
#!/usr/bin/env bash
set -euo pipefail

LANG=${1:-}
PROJECT=${2:-}

if [[ -z "$LANG" || -z "$PROJECT" ]]; then
  echo "Usage: $0 <language> <project_name>"
  exit 2
fi

mkdir -p "$PROJECT"
cd "$PROJECT"

# helpers
write_file() {
  local path="$1"; shift
  mkdir -p "$(dirname "$path")"
  cat > "$path" <<'EOF'
$*
EOF
}

# create README and .gitignore
cat > README.md <<EOF
# $PROJECT

Generated by project-scaffold

Run instructions will be added below for language: $LANG
EOF

case "$LANG" in
  python)
    mkdir -p src
    cat > src/main.py <<'PY'
print("Hello, World!")
PY
    cat > .gitignore <<'GI'
__pycache__/
*.pyc
venv/
.env
GI
    RUN_CMD="python3 src/main.py"
    ;;
  node|javascript)
    mkdir -p src
    cat > src/index.js <<'JS'
console.log('Hello, World!')
JS
    cat > .gitignore <<'GI'
node_modules/
.env
GI
    RUN_CMD="node src/index.js"
    ;;
  go)
    mkdir -p src
    cat > src/main.go <<'GO'
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
GO
    cat > .gitignore <<'GI'
/bin/
*.exe
*.out
GI
    RUN_CMD="go run ./src"
    ;;
  java)
    mkdir -p src
    cat > src/Main.java <<'JAVA'
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello, World!");
  }
}
JAVA
    cat > .gitignore <<'GI'
/bin/
*.class
out/
GI
    RUN_CMD="bash -c 'javac -d out src/Main.java && java -cp out Main'"
    ;;
  rust)
    # create cargo project layout
    cargo init --bin . >/dev/null 2>&1 || true
    # replace src/main.rs content
    cat > src/main.rs <<'RS'
fn main() {
    println!("Hello, World!");
}
RS
    RUN_CMD="cargo run"
    ;;
  *)
    echo "Language $LANG not supported by this scaffold script. Supported: python, node, go, java, rust"
    exit 3
    ;;
esac

# append run instructions to README
cat >> README.md <<EOF

## Run

To run this $LANG project:

```
$RUN_CMD
```
EOF

# verification
# 1) check source file exists
case "$LANG" in
  python)
    if [[ ! -f src/main.py ]]; then echo "Missing src/main.py"; exit 4; fi
    ;;
  node|javascript)
    if [[ ! -f src/index.js ]]; then echo "Missing src/index.js"; exit 4; fi
    ;;
  go)
    if [[ ! -f src/main.go ]]; then echo "Missing src/main.go"; exit 4; fi
    ;;
  java)
    if [[ ! -f src/Main.java ]]; then echo "Missing src/Main.java"; exit 4; fi
    ;;
  rust)
    if [[ ! -f src/main.rs ]]; then echo "Missing src/main.rs"; exit 4; fi
    ;;
esac

# 2) try running the run command (best-effort). This may fail if user environment lacks tools.
# We run in a subshell and capture exit code.
set +e
bash -c "$RUN_CMD"
RC=$?
set -e

if [[ $RC -ne 0 ]]; then
  echo "Warning: run command returned non-zero exit code: $RC"
  echo "The scaffold succeeded, but your environment may be missing the language runtime or build tools."
else
  echo "Run command executed successfully (exit code 0)."
fi

echo "Project $PROJECT created for language $LANG"
```

Примітки
-------
- Скрипт робить базовий scaffold і намагається виконати команду запуску — це 
  best-effort перевірка. У CI або локальному середовищі з відсутніми runtime'ами
  команда може повернути ненульовий код, це нормально — у README лишається інструкція.
- Щоб додати інші мови, додайте новий case і шаблони файлів.

Як використовувати Skill (приклад):

1. Скопіюйте `scripts/project-scaffold.sh` в локальний репозиторій і зробіть її виконуваною (`chmod +x`).
2. Виконайте: `./scripts/project-scaffold.sh python my-hello-project`.
3. Відкрийте `my-hello-project/README.md` — там буде команда запуску.

Важливо: цей файл — приклад Skill. Якщо ви хочете, щоб я додав цей скрипт як окремий файл `scripts/project-scaffold.sh` у репозиторій, скажіть — я додам його зараз.
