Опис проєкту Проєкт призначений для демонстрації розробки програмного забезпечення мовою Java з використанням системи автоматизації збирання Maven та фреймворку модульного тестування JUnit. У межах завдання передбачено створення репозиторію Git, розробку програмного коду, використання GitHub Copilot для допомоги в програмуванні та написання автоматизованих тестів. 
Технології:
Java — мова програмування. 
Maven — автоматизація збирання проєкту та керування залежностями.
JUnit — виконання модульного тестування. Git і GitHub — контроль версій і зберігання коду.
GitHub Copilot — допомога в написанні та аналізі коду.
